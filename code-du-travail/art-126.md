# Article 126
Si l'employeur n'a pas informé le travailleur dans les délais ci-dessus et s'il compte renouveler l'essai, il doit :
- soit avoir l'accord du travailleur ;
- soit, dans la négative, lui verser une indemnité compensatrice fixée comme suit : • huit (8) jours de salaire lorsque la période d'essai est de deux (2) mois ; • quinze (15) jours de salaire lorsque la période d'essai est de trois (3) mois.
