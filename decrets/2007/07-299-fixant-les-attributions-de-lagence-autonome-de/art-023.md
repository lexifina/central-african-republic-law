# Article 23

Les ressources de l’ARSEA proviennent de :
la perception d’une redevance telle que prévue par le code de l’eau ;
les subventions de l’Etat, d’organismes publics ou privés, nationaux ou internationaux ;
autres produits financiers ;
les dons et legs ;
toutes autres ressources qui pourraient lui être affectées ou résulter de son activité :
o les frais d’instruction de dossiers versés par les postulants ;
o les produits des amendes prévues par la Loi ;
o les recettes affectées des autorisations.
Les dépenses de l’ARSEA sont :
les dépenses de fonctionnement ;
les dépenses d’investissement ;
les services extérieurs ;
toutes autres charges inhérentes à ses activités.
