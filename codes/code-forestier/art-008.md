# Article 8

Relèvent du domaine forestier de l’Etat :
les forêts à écologie fragile ;
les forêts de production ;
les forêts récréatives ;
les forêts scientifiques ;
les jardins botaniques ;
les jardins zoologiques de l’Etat ;
les parcs nationaux ;
les périmètres de protection ;
les périmètres de reboisement ;
les réserves de faune ;
les réserves écologiques ou réserves de biosphère ;
les réserves naturelles intégrales ;
les réserves spéciales ;
les sanctuaires de faune ;
les sanctuaires de flore ;
les secteurs de chasse ;
les zones tampons ou pré parcs.
