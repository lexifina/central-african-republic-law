# Article 27

L’exploitation artisanale doit se faire dans le strict respect de l’équilibre écologique.
Les aires ouvertes à l’exploitation artisanale doivent être fermées à l’issue de l’exploitation pour permettre leur régénération.
L’octroi de permis dans le cadre de l’exploitation artisanale est strictement interdit dans les zones à écologie fragile.
