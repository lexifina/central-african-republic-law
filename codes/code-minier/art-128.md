# Article 128

En phase d'exploitation, les bénéficiaires d'une autorisation d'exploitation artisanale sont soumis au régime en vigueur dans le Code Général des Impôts. Les bénéficiaires d'une autorisation artisanale semi-mécanisée sont soumis à : la taxe sur la valeur ajoutée (TVA) ;
l'impôt sur les revenus des personnes physiques dans la catégorie des Bénéfices Industriels Commerciaux (BIG).
