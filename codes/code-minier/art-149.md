# Article 149

Pour être agent collecteur il faut remplir les conditions suivantes :
avoir une bonne moralité ;
n'avoir jamais été condamne soit pour infraction a la législation minière soit pour infraction pénale a une peine pour crime ou délit ;
ne pas être actionnaire ni employé d'une Société Minière, d'un Bureau d'Achat, d'une taillerie, d'une bijouterie ou d'une fonderie ni membre d'une coopérative minière ;
avoir payé sa patente de collecteur de l’année en cours.
