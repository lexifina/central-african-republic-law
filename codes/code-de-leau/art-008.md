# Article 8

Ne font pas partie du domaine public hydraulique :
les eaux pluviales tombées sur un fonds privé ;
les piscines, étangs, retenues d’eau artificielles construites par les personnes privées sur un fonds privé ;
les étangs et mares nés d’eaux pluviales ou les débordements des cours d’eau sur un fonds privé ;
les sources émergeant d’un fonds privé.
