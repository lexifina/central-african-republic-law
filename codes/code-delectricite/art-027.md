# Article 27

La Direction Générale de l’Agence Autonome de Régulation du Secteur de l’Electricité en République Centrafricaine peut employer :
le personnel recruté directement ;
les fonctionnaires en détachement ;
les agents de l’Etat régis par le Code de Travail.
Le personnel de l’Agence Autonome de Régulation du Secteur de l’Electricité en République Centrafricaine visé à l’alinéa cidessus doit présenter un profil adéquat aux postes qu’il occupe.
