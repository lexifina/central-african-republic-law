# Article 11

L’environnement centrafricain fait partie intégrante du patrimoine commun de l’humanité.
Il est constitué d’éléments suivants:
J.O.R.C.A. / MARS 2008 EDITION SPECIALE LOI PORTANT CODE DE L’ENVIRONNEMENT DE LA REPUBLIQUE CENTRAFRICAINE l’environnement ressource ;
l’environnement cadre de vie.
