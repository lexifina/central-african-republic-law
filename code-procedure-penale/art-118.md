# Article 118
Si le fait constitue un délit, le Juge d'Instruction renvoie le prévenu devant le tribunal correctionnel.
Si le délit peut entraîner une peine d'emprisonnement, le prévenu reste en détention.
Si le délit ne doit pas entraîner la peine d'emprisonnement, le prévenu est mis en liberté à charge pour lui de se présenter à jour fixe devant le tribunal compétent.
