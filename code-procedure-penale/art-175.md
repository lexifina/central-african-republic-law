# Article 175
Dans le dispositif de tout jugement de condamnation sont énoncés les faits dont les personnes citées seront jugées coupables ou responsables, la peine et les condamnations civiles.
Le texte de la loi dont il est fait application sera lu à l'audience par le Président ; il sera fait mention de cette lecture dans le jugement et le texte appliqué y sera produit.
Le président devra, après lecture du jugement, aviser le condamné qu'il a un délai de dix jours pour interjeter l'appel.
Mention de cet avertissement est portée dans le jugement après le dispositif.
