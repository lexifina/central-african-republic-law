# Article 229
Le délai de distance est d'un jour par 50 km lorsque le prévenu est domicilié en République Centrafricaine.
Lorsque le prévenu est domicilié dans les autres Etats de l'Afrique le délai est de deux mois.
Lorsque le prévenu est domicilié en Europe, en Asie, dans les Amériques ou en Océanie, le délai est de trois mois.
